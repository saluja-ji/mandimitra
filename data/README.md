# Data instructions

The committed sample is synthetic. For real evaluation, download a suitable commodity/date/market extract from the official Government of India OGD/AGMARKNET catalogue: https://www.data.gov.in/catalog/current-daily-price-various-commodities-various-markets-mandi

Record: download date, filters, original filename, publisher, licence/terms, unit definitions, date coverage, market coverage, missingness, and any transformations. Keep original raw data out of git if licensing, size, or terms make redistribution inappropriate. Convert to the CSV schema in the root README and preserve the original source metadata.
